# 💻 Basic Tasks in C and Python

This repository contains a collection of basic programming exercises written in **C** and **Python**.  
These tasks are designed to help beginners understand the core concepts of programming — from variables and data types to loops, functions, and conditionals.

---

## 🧩 Topics Covered
### 🟦 C Programming
- Basic input and output using `printf()` and `scanf()`
- Conditional statements (`if`, `if-else`, `switch`)
- Looping techniques (`for`, `while`, `do-while`)
- Functions and parameter passing
- String manipulation
- Arrays and basic patterns

### 🐍 Python Programming
- Input and output using `input()` and `print()`
- Conditional statements (`if`, `elif`, `else`)
- Loops (`for`, `while`)
- Functions and arguments
- Lists, strings, and dictionaries
- Simple problem-solving tasks

---
